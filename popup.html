How to use
  • Capture: Click "Capture & Copy" or press Ctrl+Shift+X
  • Select area: Drag to select region, press Escape to cancel
  • Copy: Copies latest screenshot to clipboard
  • Pin: Prevent auto-delete of a screenshot
  • God Mode: Select multiple snapshots
  • Copy Multi: Paste all selected images sequentially
  • Editor Shortcuts: Customizable above. Default: C/H/A/B, R, Enter, Esc
