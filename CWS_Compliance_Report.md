# Chrome Web Store Compliance Report for TempSnap

This report outlines the compliance audit conducted on the TempSnap extension against the Chrome Web Store Developer Program Policies.

## 1. Detected Issues
- **Manifest Setup:** The `manifest.json` file lacked the `icons` declaration, which is required for extension display in the browser and Web Store.
- **DOM Injection:** The extension used `insertAdjacentHTML` with template literals in `popup.js` to render the Recent Snaps vault. While the variables injected were local Data URLs internally generated by the extension, automated CWS static analysis tools often flag this pattern as a potential Cross-Site Scripting (XSS) vulnerability.
- **Missing Privacy Disclosure:** The extension lacked a formal Privacy Policy explaining the lifecycle of the captured screenshots.

## 2. Changes Made
- **Manifest Updated:** Appended the appropriate `"icons": {"16": "icon.png", "48": "icon.png", "128": "icon.png"}` configuration to `manifest.json`.
- **DOM Sanitization:** Refactored the UI generation logic in `popup.js`. Removed all instances of string-based HTML injection (`insertAdjacentHTML` and `innerHTML` with variables). Replaced this with direct, secure `document.createElement()` API calls to guarantee complete DOM sanitization and prevent any risk of XSS flags.
- **Privacy Documentation:** Compiled a detailed, user-facing `PrivacyPolicy.md`.

## 3. Permissions Used and Justification
The extension strictly adheres to the principle of least privilege.
- `activeTab`: Required to programmatically capture visible areas of the current page securely without requiring broad (`*://*/*`) host permissions.
- `storage`: Required to temporarily cache captured screenshots in `chrome.storage.local` before the janitor service deletes them.
- `alarms`: Required to accurately schedule the automated, background deletion of old screenshots ("Janitor" feature).
- `clipboardWrite`: Required to programmatically invoke clipboard operations from the extension's foreground and background contexts.
- `notifications`: Required to surface native browser toasts when background captures or injections succeed or fail.
- `scripting`: Required to inject the visual selection overlay (`selection.js`, `selection.css`) and the synthetic multi-paste deployment scripts natively into the active tab. 

## 4. Privacy Policy Generated
*(See `PrivacyPolicy.md` for the full text).*
TempSnap captures screenshots only on user action. Data is stored entirely locally on the user's device (`chrome.storage.local`), never uploaded or shared externally, and is automatically wiped after a user-defined timeframe (default 10 minutes).
